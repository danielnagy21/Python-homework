# F1 Python Adatelemzési Szorgalmi Feladat

Ez a projekt Formula-1-es adatok elemzését végzi a Python programozási nyelv, valamint a **pandas** és **numpy** könyvtárak segítségével.

## Fájlok a repozitóriumban:
- `Code.ipynb`: A Jupyter Notebook, amely tartalmazza a Python kódokat és a statisztikai számításokat (top pilóták, rajthelyek és pozíciók átlaga, konstruktőrök győzelmei, valamint a rajthely-pontszám korreláció).
- `document.md`: A feladat részletes dokumentációja és magyarázata.
